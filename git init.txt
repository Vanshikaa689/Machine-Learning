Why Git LFS Didn't Work
How Git LFS Works:

Git LFS replaces large files with lightweight pointers in your Git history and stores the actual file content in a separate Git LFS storage area.
However, the initial commit of the file (before being tracked by Git LFS) still exists in your Git history, triggering GitHub's file size limit.
Large File Already in Git History:

Even if you set up Git LFS and track the file, GitHub will reject the push because the large file is already in the history before being tracked by Git LFS.
